# 演示数据与样例场景

本机开发地址：http://localhost:5173/track 。演示业务内容均为虚构，不代表真实货运。

在仓库根目录运行 `pnpm seed`（等价于 `ENV_FILE=apps/api/.env.fabric go run ./apps/api/cmd/seed`），首次写入，重复执行跳过已有运单，不重置用户数据。

| 运单号                  | 演示重点                         |
| ----------------------- | -------------------------------- |
| JXSEED0001              | 正常冷链签收、完整事件与交易记录 |

| JXSEED0007              | 已揽收                           |

公开查询首页提供四个快捷入口，查询结果来自 API 和 Fabric，不是硬编码轨迹。样例步骤在播种时连续提交，时间表示实际提交时间，不模拟数天的真实运输时间。样例上的文件摘要对应合成文本，不代表已存储的实际附件。

## 运输控制塔

控制塔与运单业务使用同一条链码、同一本账本（见 [INTEGRATION.md](../INTEGRATION.md)）：

- `LEDGER_MODE=fabric` 时直接查询上方 JXSEED 运单（如 `JXSEED0004` 在途场景）。
- `LEDGER_MODE=mock`（默认）时查询 `YT20260001`，返回内置演示路线，响应标注 `dataSource: demo`。
- 双边交接演示：Org1 服务（8080）发起 `InitiateHandover`，Org2 服务（8082）`ConfirmHandover` 确认；发起方自行确认与重复确认都会被链码拒绝。

遥测、网点与路线是演示数据；接入 MySQL 不等同于接入真实 GPS/温湿度设备。

## 演示文件导入

以发货方登录 → 运单管理 → 批量导入 → 下载 3 条演示数据 → 选择下载的 CSV → 检查预览 → 提交导入。

文件位于 `apps/web/public/demo-shipments.csv`，包含医药冷链、常温电子设备、冷冻海产三种温控要求。联系电话和地址为演示占位，请勿实际联系。预计送达日期为 2026-12-31，跨年演示请先更新。

CSV 导入只创建待接单运单，不伪造后续事件。每次导入会新建运单，不具备重复文件去重功能。导入完成立即下载结果并保管一次性签收码；后续由承运方接单、更新轨迹，收货方确认。
