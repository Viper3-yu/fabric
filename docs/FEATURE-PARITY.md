# 原项目功能保留与区块链展示说明

## 功能核对

| 原项目能力           | 当前状态         | 调整方式                                      |
| -------------------- | ---------------- | --------------------------------------------- |
| 公开物流查询         | 保留             | 继续使用 `/track`，展示脱敏物流与链上记录标识 |
| 链上核验             | 保留             | 继续使用 `/verify`，核验事件连续性与证据摘要  |
| 登录与工作台         | 保留             | 继续使用 `/login` 与 `/app`                   |
| 运单列表、创建、详情 | 保留             | 保留原路由，并简化详情页的信息层级            |
| 首页营销介绍         | 未放入业务控制台 | 与业务操作无关的展示内容不占用后台导航        |

当前版本没有删除原项目的核心业务路由。主要变化是重新组织导航与详情页，并新增控制塔、跨组织交接、集成设置和批量导入演示。

## 区块链主题如何体现

当前演示不建设完整区块浏览器。答辩时用三处可核验能力说明区块链价值：

1. 运单详情的“区块链凭证”展示交易 ID、提交组织、时间和业务事件。
2. 公开核验页检查运单历史连续性和证据摘要，说明记录是否被修改。
3. 跨组织交接分别记录交出方和接收方的确认交易，说明责任边界如何留痕。

完整区块浏览器会引入区块高度、通道、节点和原始载荷等底层信息，容易与业务演示重复。若后续需要增强，可增加一个轻量“交易详情”抽屉；只有后端能够稳定返回区块号与验证状态时，才展示这些字段。

## 定位数据边界

道路路线和连续 GPS 点属于链下高频数据。当前演示把 OSRM/OpenStreetMap 生成的杭州至南京道路几何固化在前端数据中，用蓝色展示已上报位置，用灰色展示剩余路线。生产环境应由车辆设备或承运商接口持续上报坐标，再把关键节点、责任交接和证据摘要写入 Fabric。
