## 浏览器闭环验收

本次验收通过真实浏览器和本地 API 完成，不是只调用单元测试。

验收运单：`JX20260720349090`

1. 发货方创建冷链运单，系统生成一次性签收码。
2. 承运方接单并确认揽收。
3. 承运方提交 10.5°C 节点；系统依据 2–8°C 温区自动生成异常事件并转为“运输异常”。
4. 承运方提交异常处置说明和证据摘要，运单恢复“运输中”。
5. 承运方提交送达凭证摘要，状态转为“待签收”。
6. 收货方使用一次性签收码确认收货，状态转为“已签收”，页面显示“业务闭环完成”。
7. 无需登录的公开查询返回 8 个连续事件、1 次异常、组织与交易回执，并将收货信息显示为 `陈** · 139****9002`。
