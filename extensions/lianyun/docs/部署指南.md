# WSL 部署指南

本项目已按 Ubuntu 24.04 + systemd 的 WSL 环境整理为可重复部署流程。正式模式由 Apache/PHP 前端、Go Gin API、MySQL 8、Hyperledger Fabric 2.5 test-network 与 Go 链码组成。

## 1. 环境要求

- WSL 2 Ubuntu，已启用 systemd；
- Go 1.21+、Node.js 18+、PHP 8+、Apache 2、MySQL 8；
- 可用的 Linux Docker Engine 或 Docker Desktop WSL 集成（二选一，避免同时运行两套守护进程）；
- Git 与 curl。

快速检查：

```bash
go version
node -v
php -v
mysql --version
docker version
systemctl is-active mysql apache2 docker
```

## 2. 安装 Fabric

```bash
chmod +x scripts/wsl/*.sh
./scripts/wsl/install-fabric.sh
```

脚本固定使用 Fabric `2.5.16`、Fabric CA `1.5.17`，并将 `fabric-samples` 固定到已验证提交 `05edea0`。安装目录为 `~/hyperledger/fabric-samples`。可通过 `LIANYUN_FABRIC_HOME` 和 `LIANYUN_SAMPLES_COMMIT` 覆盖目录或 samples 提交。

## 3. 一键部署正式模式

```bash
./scripts/wsl/deploy.sh
```

脚本将执行：

1. 启动 Docker、MySQL 与 Apache；
2. 创建 `lianyun` 数据库和仅限本机的 `lianyun_app` 用户；
3. 启动双组织 Fabric 网络（LevelDB 状态库）并创建 `logisticschannel`；
4. 部署 `lianyun` Go 链码并执行幂等的 `InitLedger`；
5. 解析 Org1 User1 的证书、私钥和 TLS CA，生成 `backend-go/.env`；
6. 编译后端并注册 `lianyun-backend.service`；
7. 在 Apache `8081` 端口发布 PHP 前端，并反向代理 `/api` 到 Gin。

为兼容 Windows 保留端口和桌面代理占用，脚本把 Fabric 对外端口统一映射到 `21050/21051/22051/21054/22054/23054`。对应的 `LIANYUN_*_PORT` 环境变量可覆盖这些值。

访问地址：

- 前端：`http://localhost:8081`
- API 健康检查：`http://localhost:8080/api/health`
- 演示运单：`YT20260001`

## 4. 状态与日志

```bash
./scripts/wsl/status.sh
./scripts/wsl/smoke-test.sh
sudo journalctl -u lianyun-backend -n 100 --no-pager
docker ps
```

健康检查在正式模式应返回 `"mode":"fabric"`。冒烟测试会真实写入一条验收事件，并检查事件数增加及交易 ID。控制塔接口的运单和事件来自 Fabric，网点、路线、GPS 与温湿度来自 MySQL。

## 5. Windows 登录后保持 WSL 服务在线

WSL 可能在没有前台 Linux 会话时休眠。需要长期通过 Windows `localhost` 访问时，在项目根目录用 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows\keep-wsl-alive.ps1
```

脚本注册当前用户的 `LianyunWSLKeepAlive` 登录任务，并立即启动。它不会修改 Linux 服务配置，也不会占用额外业务端口。

## 6. 停止环境

```bash
./scripts/wsl/stop.sh
```

该命令停止后端并关闭课程专用的 Fabric test-network，不删除 MySQL 数据。

## 7. 无 Fabric 的展示模式

```bash
cd mock-demo
npm install
npm test
npm start
```

浏览器访问 `http://localhost:3100`。此模式只用于快速展示，不应在答辩中声称已连接真实 Fabric。
