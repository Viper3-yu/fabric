# API 说明

| 方法 | 路径                              | 用途                            |
| ---- | --------------------------------- | ------------------------------- |
| POST | /api/auth/login                   | 登录并获取令牌                  |
| GET  | /api/health                       | 健康检查                        |
| GET  | /api/shipments/{id}/control-tower | GIS、运单、风险、温湿度聚合数据 |
| GET  | /api/shipments/{id}/map           | 地图路线数据                    |
| GET  | /api/shipments/{id}/risk-analysis | 风险段与异常清单                |
| POST | /api/shipments/{id}/events        | 追加节点事件                    |

控制塔接口将 MySQL 的网点/路线/GPS/温湿度与 Fabric 的链上事件合成后返回。前端不直接连接 Fabric。

## 风险字段

- `DELAY`：实际到达超过计划到达。
- `ROUTE_DEVIATION`：连续 GPS 点偏离计划折线超过阈值。
- `EXCEPTION`：链上异常事件。
- `HANDOVER_TIMEOUT`：发起交接后超时未确认。
- `EVIDENCE_MISMATCH`：文件重新计算的 SHA-256 与链上哈希不同。
