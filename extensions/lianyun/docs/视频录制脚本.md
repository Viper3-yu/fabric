# 链运协同演示视频录制脚本

建议时长：6–8 分钟。演示环境可先用 `mock-demo`，再说明通过 `LEDGER_MODE=fabric` 切换为真实 Fabric Gateway。

| 时间      | 画面与操作          | 讲解要点                                                                                                   |
| --------- | ------------------- | ---------------------------------------------------------------------------------------------------------- |
| 0:00–0:35 | 封面与系统首页      | 选题 9；系统解决多方物流交接、单证校验与异常溯源问题。                                                     |
| 0:35–1:20 | 架构图 / 控制塔首页 | 链上保存共同认可的摘要和事件；MySQL 保存网点、路线、原始遥测；文件存储保存回单。                           |
| 1:20–2:15 | 查询 `YT20260001`   | 展示地图、当前状态、时间线和包裹/物流单元关系。说明绿色、蓝色、红色/橙色路段的含义。                       |
| 2:15–3:15 | 演示交接流程        | 货主创建运单/包裹；承运方装载并发起交接；接收方确认。强调智能合约根据 MSP 限制操作组织。                   |
| 3:15–4:10 | 演示异常与证据      | 追加“延误”或“单证待确认”事件；打开风险项，使地图定位到对应路段；展示证据 SHA-256 哈希上链。                |
| 4:10–5:10 | 插件说明            | GPS 插件计算轨迹点到规划路线的偏离距离；温湿度插件读取 CSV、统计异常次数。原始数据不上链，只锚定汇总哈希。 |
| 5:10–6:10 | 代码与接口          | 展示 Go 链码的 `InitiateHandover` / `ConfirmHandover`，以及控制塔 API 返回地图、风险和时间线的聚合结果。   |
| 6:10–7:00 | 测试与总结          | 展示 API 测试通过：控制塔数据、404、追加事件。总结聚合/拆分、双边交接确认、GIS 风险联动三个亮点。          |

## 演示前检查

1. 进入 `mock-demo` 执行 `npm install` 与 `npm test`，然后 `npm start`。
2. 浏览器访问 `http://localhost:3000`，确认可看到运单 `YT20260001`。
3. 预先打开 `docs/架构设计.md`、`chaincode-go/main.go`、`docs/接口说明.md` 三个窗口。
4. 录制时避免夸大：GIS 风险只表示“待核查范围”，系统不自动判定责任。
