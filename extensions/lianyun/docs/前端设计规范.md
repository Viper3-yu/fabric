# 前端设计规范

## 视觉定位

以 SAP Global Track and Trace、FourKites 和 Descartes 一类物流控制塔为参考：强调操作、例外处置和证据检索，而非营销感或 AI 概念包装。

## 禁止项

- 禁止渐变、高光、玻璃拟态、漂浮大圆角卡片。
- 禁止 emoji、3D 装饰插画、无信息量的大数字。
- 禁止“智能洞察”“一键掌控”等泛化文案。
- 禁止把地图当背景图；地图必须可以点击运输段、网点和风险。

## 版式

- 左侧 224px 深蓝导航；顶部为面包屑、页面标题、更新时间和操作。
- 控制塔页中地图占主要工作区域，右侧固定为风险/证据面板。
- 数据操作优先用表格、时间线、筛选工具栏；仪表卡只用于少量任务概览。
- 状态颜色固定：正常绿、运输中蓝、预警黄、异常红、计划灰。

## 交互

- 地图、时间线、风险列表三向联动。
- 点击风险项定位路线段，并显示对应交易 ID 和证据哈希。
- 点击网点读取该节点最近的链上事件。
- 小屏幕下先显示地图，再显示风险、时间线和表格。
