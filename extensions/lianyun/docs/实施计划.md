# 实施计划

| 阶段 | 内容               | 验收结果                                          |
| ---- | ------------------ | ------------------------------------------------- |
| 1    | 链上数据模型与链码 | 运单、包裹、装箱/拆箱、交接、异常、凭证交易可提交 |
| 2    | Gin + MySQL        | 登录、控制塔聚合接口、风险规则、审计接口          |
| 3    | PHP 控制塔         | 地图、时间线、风险、证据、包裹物流单元表格        |
| 4    | 遥测插件           | GPS/温湿度模拟数据、路线偏离和阈值风险            |
| 5    | 联调与材料         | Fabric 模式截图、验收用例、PPT、录屏              |

当前已完成阶段 1 的源码、阶段 2 的 Mock API、阶段 3 的控制塔页面以及阶段 4 的模拟数据和风险展示。正式 Fabric Gateway、MySQL 仓储和 PHP/Apache 的本机运行按部署指南接入。
